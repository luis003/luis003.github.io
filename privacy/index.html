Privacy policy: 003-os

Last updated 2026-11-19

003-os is a single-user personal assistant run by its owner for their own accounts. It is not offered to the public.

What it accesses

With consent given through Google sign-in, it reads Gmail messages and Calendar events, and creates or updates events on calendars the signed-in user owns. It requests no other Google data.

How data is used

Data is processed only to produce the owner's own summaries and calendar availability. It is not sold, shared with third parties, or used for advertising. Message content is not stored after processing; only operational metadata, such as sync checkpoints, is kept.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
